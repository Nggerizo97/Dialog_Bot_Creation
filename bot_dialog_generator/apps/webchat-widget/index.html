Bot_Dialog_Generator Assistant Demo

This page embeds the Bot_Dialog_Generator Webchat Lit component for preview and testing.

The widget below is configured the way a public bot would be: it asks for authorization before the first message (require-authorization), offers the optional analytics opt-in (analytics-url) and links the legal documents served by the studio. The demo attribute answers with sample replies when no gateway is running; never set it on a real site.
